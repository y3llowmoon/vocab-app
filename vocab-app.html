☁ 기기 간 자료 동기화 (GitHub)

단어 자료를 내 GitHub 저장소의 data.json 파일에 저장해서 PC·스마트폰이 같은 자료를 씁니다. 읽기는 누구나(토큰 불필요), 수정은 토큰을 입력한 기기에서만 됩니다. 테스트 결과 기록은 각 기기에만 저장됩니다.

토큰 만드는 방법 (한 번만)

  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Expiration(만료일)은 길게(예: 1년), Repository access → Only select repositories에서 단어장 저장소 하나만 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token을 누르고 나온 github_pat_... 문자열을 위 칸에 붙여넣은 뒤 설정 저장

⚠ 토큰은 비밀번호처럼 다루세요. 저장소에 올리거나 남에게 공유하지 마세요.
